## Criação do Agente
Este agente foi criado à partir da pasta "../Workspaces/adk_workspace/" com o comando:
```sh
adk create --type=config my_config_agent
```

Na criação foi passada a API Key que então foi configurada na chave GOOGLE_API_KEY do arquivo .env

## Execução
Para execução utiliza-se os mesmos métodos ADK
web, run ou api_server
